一、我们如何收集和使用个人信息

我们会遵循"合法、正当、必要、诚信"原则，仅在提供下列功能所必需的范围内收集和使用您的个人信息。 若某功能属于非必要功能，我们会在具体功能场景中以弹窗、勾选框等方式再次征得您的明示同意。

1.1 账号注册、登录与身份认证（核心功能）

依据《常见类型移动互联网应用程序必要个人信息范围规定》，移动智能终端厂商预置的安全防护/工具类应用（APP）原则上可不收集敏感个人信息；但本应用提供账号体系 + 多设备绑定功能，因此需收集：

  • 邮箱地址：用于账号识别、接收验证码、找回密码、接收重要通知（如账号安全提醒、政策更新）。
  • 邮箱验证码/认证信息：用于完成登录验证与身份核验。
  • 账号标识（user_id / token）：用于维持您的登录状态。

上述信息为使用本应用核心功能所必需；如您拒绝提供，将无法完成登录，也无法绑定或管理您的设备。

1.2 设备绑定与智能安防功能（核心功能）

当您通过二维码扫描或手动输入等方式将"闲置手机"绑定为本应用的"摄像端设备"，并使用"监控端"进行远程查看时，我们会处理：

  • 相机设备标识（如 camera_device_id）、绑定时间戳：用于建立账号与设备的绑定关系。
  • 相机名称、房间/位置信息：由您自行输入或修改，便于您区分多个摄像头。
  • 设备在线状态、信令会话标识（SDP/ICE 候选、会话 ID）：用于建立 WebRTC 点对点连接，实现音视频实时推送。
  • 若您选择开启"云端录像 / 云端留存"（如后续版本提供），云端将存储检测到的录像片段； 该功能默认关闭，首次启用时我们会通过显著弹窗再次征得您的明示同意。

1.3 设备信息与运行日志（安全合规必需）

为保障账号安全、服务稳定性、防滥用风控、以及排查故障，我们会在服务运行过程中自动收集：

  • 设备型号、操作系统版本、设备制造商、屏幕分辨率、应用版本号、网络类型（Wi-Fi/4G/5G）。
  • IP 地址（仅用于大致地区判断、风控及反作弊，不会精确到街道或门牌号）。
  • 崩溃日志、性能数据（加载耗时、帧率）、错误码、操作日志（如登录时间、绑定动作）。

我们会采用去标识化、聚合、抽样等技术手段对上述信息进行保护，不会直接关联到您的真实身份（除非法律法规要求或账号安全场景需要）。

1.4 权限调用说明（逐项明示）

本应用在不同功能场景中可能会调用以下系统权限。所有权限均非默认开启，仅在您进入对应功能时通过系统弹窗逐项征得您的同意，您也可以随时在系统设置中关闭：

  • 相机权限（CAMERA）：① 摄像端：采集视频画面；② 监控端：扫描设备二维码绑定。拒绝后无法采集画面或扫码绑定。
  • 麦克风权限（RECORD_AUDIO）：① 摄像端：采集声音；② 监控端：双向语音对讲。拒绝后无法传输声音或对讲。
  • 相册/存储权限（READ/WRITE_EXTERNAL_STORAGE / Photo Library）：在监控端主动点击"保存到相册"时，将录像保存到您的本机相册/图库。拒绝后无法保存到相册，但不影响实时观看。
  • 前台服务（FOREGROUND_SERVICE / START_FOREGROUND）：Android 摄像端锁屏或切后台时持续采集音视频。拒绝后后台采集可能中断。
  • 通知权限（POST_NOTIFICATIONS）：推送告警通知、账号安全提醒。拒绝后无法收到推送，但可在 App 内查看历史消息。

关于音视频内容：在默认情况下，您的实时音视频内容通过 WebRTC 点对点（P2P）直接传输到您自己的监控端设备， 我们不会主动存储、监听或查看您的音视频内容。仅在 P2P 连接不可用时，经 TURN 中继短暂转发（采用加密通道）， 转发内容不会被落盘保存。

1.5 广告与第三方 SDK（国内版）

国内版本应用可能接入字节跳动穿山甲（Pangle）或其他合规的第三方广告 SDK 以展示广告。 相关 SDK 可能会收集设备标识（如 OAID、Android ID、IDFA）、网络信息、应用交互信息、粗略地理位置信息等， 用于广告投放、频控、归因与反作弊。我们会要求第三方 SDK 提供方在处理您的信息时遵守相应的法律法规， 并对其进行合理监督。您可以通过应用内"隐私设置"或系统"重置广告标识符"来管理个性化推荐。

我们承诺：即便接入第三方广告 SDK，也不会将您的邮箱、账号身份、音视频画面等核心敏感信息提供给广告 SDK， 用于广告投放的仅为去标识化后的设备标识。

1.6 个性化推荐的说明与关闭方式

若我们或第三方广告 SDK 向您提供个性化推荐（即基于您的行为画像投放更精准的广告）， 我们会在开启该功能前再次通过弹窗征得您的明示同意。您可以随时：

  • 进入「通用设置 → 隐私设置 → 个性化推荐」将其关闭；关闭后推荐总量不变，但相关度可能下降。
  • 在 Android 系统「设置 → 隐私 → 广告」中选择"重置广告 ID"或"选择退出广告个性化"。

1.7 征得同意的例外

依据《个人信息保护法》第十三条，在以下情形中我们可能处理您的个人信息而无需另行取得您的同意：

  • 为订立、履行您作为一方当事人的合同所必需；
  • 为履行我们的法定义务所必需（如配合监管、税务、司法调查）；
  • 为应对突发公共卫生事件，或紧急情况下为保护您或他人的生命、健康和财产安全；
  • 为公共利益实施新闻报道、舆论监督等行为，在合理范围内处理个人信息；
  • 在合理范围内处理您自行公开或其他已经合法公开的个人信息；
  • 法律法规规定的其他情形。

二、我们如何使用 Cookie 和同类技术

本应用主要为移动端 App，但在部分 H5 页面（如本隐私政策页面、服务条款页面）中可能使用 Cookie / LocalStorage 用于记住您的阅读状态与主题偏好。我们不会使用 Cookie 进行跨站跟踪，也不会在其中存储您的账号密码等敏感信息。 您可以在浏览器设置中清除或拒绝 Cookie。

三、我们如何共享、转让、公开披露个人信息

2.1 共享

我们不会向任何公司、组织和个人出售您的个人信息。仅在以下情形下，我们会在"最小必要"原则下共享您的个人信息：

  • 在获取您明确同意后共享：在通过弹窗、勾选框等方式获得您的明示同意后，向您指定的第三方共享。
  • 与关联公司共享：仅为实现本政策目的，与我们的关联公司在必要范围内共享（如共享去标识化的设备标识用于广告与风控）。
  • 与授权合作伙伴共享：
    • STUN / TURN / 网络服务提供方：用于建立 WebRTC 连接；仅涉及网络传输必要信息（IP、信令候选）。
    • 广告 SDK 提供方：见§1.5 说明。
    • 云服务提供方：我们使用国内合规云服务商（如阿里云/腾讯云）托管服务器，其会按照合同约定承担个人信息保护义务。
  • 依法共享：根据法律法规规定、诉讼争议解决需要，或行政、司法机关依法提出的要求。

对我们与之共享信息的公司、组织和个人，我们会通过合同约定、审计、尽调等方式，要求其按照我们的说明、本隐私政策以及其他任何相关的保密和安全措施处理信息。

2.2 转让

我们不会将您的个人信息转让给任何公司、组织和个人，但以下情形除外：

  • 在获取您明确同意后转让；
  • 在涉及合并、收购、资产转让或类似的交易时，如涉及个人信息转让，我们会要求新的持有您个人信息的公司、组织继续受本政策约束， 否则我们将要求该公司、组织重新向您征求授权同意。

2.3 公开披露

我们仅会在以下情形下，公开披露您的个人信息：

  • 获得您的明确同意；
  • 基于法律的披露：在法律、法律程序、诉讼或政府主管部门强制性要求的情况下，我们可能会公开披露您的个人信息。

四、我们如何存储和保护个人信息

4.1 存储地域

原则上，我们在中华人民共和国境内收集和产生的个人信息，将存储在中华人民共和国境内。 目前我们不会向境外传输您的个人信息。如未来因业务需要确需跨境传输，我们会严格遵守《个人信息保护法》 关于跨境提供个人信息的相关规定（包括安全评估、标准合同、认证等），并单独征得您的明示同意。

4.2 存储期限

我们仅在实现本政策所述目的所必需的期间内保留您的个人信息：

  • 账号信息：至您注销账号后 15 个工作日 内删除或匿名化（法律另有规定的除外）。
  • 设备绑定信息：随账号一并删除；或您主动解绑时即时删除。
  • 登录日志、操作日志：一般保留 不少于 6 个月，不超过 3 年（满足《网络安全法》第 21 条日志留存要求）。
  • 云端录像（如启用）：根据您选择的套餐（7 天 / 30 天）循环覆盖存储，超出留存期自动删除。

超出上述存储期限后，我们将对您的个人信息进行删除或匿名化处理。 匿名化处理后的信息将无法复原，也无法再识别到特定自然人。

4.3 安全保护措施

我们已采取符合业界标准、合理可行的安全防护措施保护您的信息：

  • 传输安全：账号接口、WebRTC 信令接口全面启用 HTTPS/TLS 加密。
  • 存储安全：敏感字段（如邮箱）采用加密存储；密码采用加盐哈希算法（bcrypt）单向存储，即使我们也无法还原。
  • 访问控制：建立最小权限访问机制，仅授权必要人员访问；关键操作均有审计日志。
  • 数据分级与分类：我们将信息分为公开信息、一般个人信息、敏感个人信息，并对敏感信息采取更高级别的保护。
  • 安全审计与加固：定期开展渗透测试、漏洞扫描、代码审计。

尽管采取了上述合理且必要的措施，请您理解互联网环境并非百分之百安全。一旦发生或可能发生个人信息泄露、篡改、丢失等安全事件， 我们将按照《个人信息保护法》第 57 条规定，在 72 小时内向履行个人信息保护职责的部门报告，并以邮件、弹窗、公告等方式告知您： 安全事件的基本情况和可能的影响、我们已采取或将要采取的处置措施、您可自主防范和降低风险的建议、对您的补救措施等。

五、您的权利（查询、更正、删除、撤回、注销）

依据《个人信息保护法》第四章，您对您的个人信息享有以下权利：

5.1 知情权、决定权与查阅复制权

  • 您可以随时在「通用设置 → 账号与安全」中查阅您的账号信息（邮箱、绑定的设备列表）。
  • 如您需要获取您的个人信息副本（个人信息导出），请通过邮箱联系我们（见§十），我们会在 15 个工作日内响应。

5.2 更正权

当您发现我们处理的关于您的个人信息有误或不完整时，您有权要求我们作出更正或补充。 您可在「通用设置 → 账号与安全」中自助操作，或通过§十提供的方式联系我们。

5.3 删除权

在以下情形中，您可以向我们提出删除个人信息的请求：

  • 处理目的已实现、无法实现或者为实现处理目的不再必要；
  • 我们停止提供产品或者服务，或者保存期限已届满；
  • 您撤回同意；
  • 我们违反法律、行政法规或者违反约定处理个人信息；
  • 法律、行政法规规定的其他情形。

若我们决定响应您的删除请求，我们还将同时通知从我们获得您的个人信息的实体，要求其及时删除（法律法规另有规定或实体获得您独立授权的除外）。

5.4 撤回同意与关闭权限

每个业务功能需要一些基本的个人信息才能得以完成（见§一）。对于您额外授权同意的相机、麦克风、相册、通知等权限， 您可以通过以下方式随时撤回您的授权同意：

  • Android：进入「系统设置 → 应用管理 → RePhone Security → 权限管理」逐项关闭。
  • iOS：进入「设置 → RePhone Security → 权限」逐项关闭。

请您理解，当您撤回某项同意或关闭权限后，我们无法继续为您提供该同意/权限所对应的服务， 相应的特定业务功能会自动退出或不可用，但不会影响此前基于您的同意已开展的个人信息处理。

5.5 注销账号（明确注销流程与时效）

您有权随时注销您已注册的账号。注销账号后，我们将停止为您提供产品或服务，并依据法律法规要求删除您的个人信息或做匿名化处理。

注销路径（国内版统一）：

  1. 登录 App → 进入「我的 / 设置」 → 「通用设置」→「注销账号」。
  2. 阅读并确认注销提示（注销将导致：① 所有绑定设备自动解绑；② 云端录像立即删除且无法恢复；③ 会员权益（如有）终止且不退款）。
  3. 完成身份核验：输入当前账号邮箱并点击"发送验证码"，输入收到的 6 位邮箱验证码。
  4. 二次确认：点击"确认注销本账号"，系统将进入"注销冷静期（7 天）"。
  5. 冷静期内您可重新登录撤回注销；7 天冷静期届满后，系统将自动注销账号并删除/匿名化您的个人信息。 若法律法规另有要求（如需保留 6 个月~3 年的日志），我们会在保留期限届满后再行删除。
  6. 注销完成后您会收到邮件通知。

若您通过 App 内路径无法完成注销，可随时通过邮箱 dahongwudi123@gmail.com 申请人工注销， 我们将在 15 个工作日内响应并完成核验处理。

5.6 死者个人信息的处理

自然人死亡后，其近亲属为了自身的合法、正当利益，可以对死者的相关个人信息行使本章规定的查阅、复制、更正、删除等权利； 死者生前另有安排的除外。

5.7 响应您的请求

为保障安全，您可能需要提供书面请求或以其他方式证明您的身份。我们可能会先要求您验证自己的身份，然后再处理您的请求。 我们将在 15 个工作日内 做出答复。如您不满意，还可以通过§十的邮箱发起投诉。 对于您合理的请求，我们原则上不收取费用；对多次重复、超出合理限度的请求，我们将视情收取一定成本费用。 与个人信息主体无关、需要过多技术手段、给他人合法权益带来风险、不切实际的请求，我们可能会予以拒绝并说明理由。

六、儿童个人信息的特别保护规则

儿童隐私政策（依据《未成年人网络保护条例》单独制定）
本条款为《RePhone Security 隐私政策》不可分割的组成部分，仅适用于未满 14 周岁的未成年人（即"儿童"）； 已满 14 周岁未满 18 周岁的未成年人适用《隐私政策》通用条款，但应在监护人的指导下使用本应用。
  • 本应用的主要服务对象为具备完全民事行为能力的成年人。我们非常重视对儿童个人信息的保护。 若您是未满 14 周岁的儿童，请您在注册、使用本应用前，务必事先取得您的父母或其他监护人（以下简称"监护人"）的书面同意； 我们将依据本政策在监护人同意的范围内处理儿童个人信息。
  • 我们不会主动以定向推送为目的向儿童收集个人信息，不会向第三方共享儿童个人信息（除法律法规要求或经监护人同意外）， 也不会在儿童未勾选同意的情况下诱导儿童授权不必要的系统权限。
  • 儿童个人信息的存储：我们将采取与成年用户同等或更严格的加密与访问控制措施；除日志留存的法定期限要求外， 在实现目的所需的最短期限内存储，到期即自动删除或匿名化。
