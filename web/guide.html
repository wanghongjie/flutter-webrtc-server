两部手机，两种角色
监控端：您日常使用的手机，需要用邮箱注册登录，用来随时查看画面。
相机端：那台闲置的手机，放在需要监控的位置，不需要注册、不需要登录， 扫一下监控端的二维码即可完成绑定。
目录

一、注册账号（监控端）

  1. 打开 RePhone Security，勾选同意《服务条款》《隐私政策》后，点击「使用邮箱登录」。
  2. 输入您的邮箱地址（需包含 @ 与域名，如 name@example.com），点「下一步」。
  3. 系统会检测该邮箱是否已注册：
    • 未注册 → 发送 6 位数字验证码（有效期约 10 分钟）；
    • 已注册 → 直接进入密码登录页。
  4. 填入收到的验证码，进入设置密码页面。
  5. 设置密码：至少 8 位，且必须同时包含字母和数字；确认后提交即注册成功。
收不到验证码？
检查垃圾邮件 / 推广邮件文件夹 · 确认邮箱地址无误 · 验证码 10 分钟内有效，超时请重新获取 · 部分企业邮箱会拦截外部邮件，建议改用个人邮箱。

二、登录与密码管理

2.1 登录

在登录页输入注册邮箱 + 密码，登录状态会保留，下次打开 App 自动进入。

2.2 忘记密码

  1. 登录页点「忘记密码？」；
  2. 输入注册邮箱 → 获取验证码；
  3. 填写验证码 + 新密码（≥8 位，含字母和数字）→ 提交；
  4. 返回登录页用新密码登录。

2.3 修改密码

登录后：我的 → 通用设置 → 重置密码，输入原密码 + 新密码 + 确认新密码即可。 （同页面还可设置语言、管理权限、注销账号、退出登录。）

三、绑定相机（核心步骤）

准备两部手机：A = 监控端（已登录）、B = 相机端（闲置手机，装好 App）。

3.1 在监控端（A）生成二维码

  1. 用邮箱登录 A 手机，进入底部「相机」列表页；
  2. 点击右下角 + 按钮；
  3. 页面显示一个二维码并标注「监控端邮箱」，保持该页面不要退出。

3.2 在相机端（B）扫描绑定

  1. 在 B 手机打开 App，点击「扫码绑定」（需允许相机权限）；
  2. 扫描 A 手机上的二维码；
  3. B 手机提示绑定成功后进入相机端界面，顶部显示「已连接服务器 (ID: xxxx)」；
  4. 几秒后 A 手机的相机列表会自动出现这台新相机，点进去即可观看实时画面。
扫描时提示「二维码格式不正确」？
相机端只识别 RePhone 生成的邮箱二维码（内容是一个邮箱地址）。 请确认扫的是监控端「相机 → +」页面里的二维码，而不是其它二维码。

3.3 绑定后要做的事

  • 授予权限：相机、麦克风、通知都要允许，否则无法采集画面/声音。
  • 保持在线：按《常见问题：让相机端一直在线》关闭电池优化、允许后台运行。
  • 改名 / 改位置：监控端相机列表 → 该设备「设置」→ 修改名称与位置（如「客厅」）。
  • 删除设备：同一设置页可删除绑定；删除后该相机端需重新扫码。

四、两台手机之间的角色切换

同一个 App 可通过左上角角色菜单在「监控端 / 相机端」之间切换：

  • 切换到相机端：会退出当前登录，提示「请扫监控端的二维码进行绑定」；
  • 切换到监控端：需要用邮箱登录。

建议：闲置手机固定当作相机端，不要频繁切换。

五、可以绑定多台相机吗？

可以。重复第三节的步骤即可绑定多台相机，列表会显示每台设备的 在线状态、名称/位置、最后活跃时间，并支持逐台回看与设置。

六、常见问题排查

现象原因与处理
监控端列表里相机一直「离线」 相机端后台被系统冻结。请按《常见问题：让相机端一直在线》完成电池优化与后台设置，并保持相机端 App 在前台 / 通知栏常驻。
能看到设备但画面黑屏 / 加载很久 检查镜头是否被遮挡或被其它应用占用；确认两端网络；重启相机端 App 后重试。
扫码后提示绑定失败 确认监控端已登录且网络正常；返回重新生成二维码再扫。
换手机后设备不见了 用同一个邮箱登录监控端即可恢复绑定关系；相机端需重新扫码一次。
想让别人也看这台相机 绑定基于账号，对方的相机端可扫描同一个监控端邮箱的二维码。
