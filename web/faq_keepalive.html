常见问题：让相机端一直在线
RePhone Security：自启动 / 后台运行 / 电池优化设置指引（国际版）
更新日期：2026-10-10 · 适用：相机端手机（Android / iOS）
为什么要做这些设置？
RePhone Security 把一部闲置手机变成摄像头。为了省电，安卓系统默认会在锁屏一段时间后 冻结或杀掉后台应用，导致监控端连不上相机。做好这 3 件事即可长期稳定在线： ① 关闭电池优化、② 允许后台运行/自启动、③ 开启通知权限（保持前台服务常驻）。
目录

一、先做这 3 步（所有安卓手机通用）

  1. 关闭电池优化：进入相机端时，App 会先弹出说明弹窗告知用途，您点击 「同意并继续」后才会跳转到系统的电池优化授权页，请选择 「允许 / 不优化」。若点了「暂不开启」：设置 → 应用 → RePhone Security → 电池 → 选择 「不受限制 / 不优化」。
  2. 开启通知权限：相机端依靠「常驻通知」保持前台服务。若关闭通知权限，App 会提示 「需要通知权限以保持相机在后台运行」，请到 设置 → 应用 → RePhone Security → 通知 打开。
  3. 允许后台运行 / 自启动：设置 → 应用 → RePhone Security → 移动数据与 WLAN → 打开后台数据与不限流量使用；并在最近任务界面长按应用卡片选择「锁定」， 防止一键清理时被清掉。
怎么确认设置成功了？
相机端提示「电池优化已关闭，运行状态良好」，且通知栏常驻 「相机端运行中」。 若提示「建议在设置中关闭电池优化以保证连接稳定」，说明第 1 步还没生效。

二、各品牌手机的具体路径（Android）

不同系统版本菜单名称略有差异，可在设置中搜索「电池优化」「后台」「自启动」等关键词。

品牌 / 系统操作路径
Google Pixel（原生 Android） 设置 → 应用 → RePhone Security → 电池 → 不受限制；
设置 → 电池 → 关闭省电模式与自适应电池对该应用的限制。
三星（One UI） 设置 → 电池与设备维护 → 电池 → 后台使用限制 → 把本应用加入 「从不休眠的应用」，并关闭「让未使用的应用进入休眠」；
设置 → 应用程序 → RePhone Security → 电池 → 不受限制。
小米 / Redmi / POCO（MIUI、HyperOS 国际版） 设置 → 应用 → 管理应用 → RePhone Security → 打开自启动；
同一页面 → 省电策略 → 无限制；
安全中心 → 电池 → 关闭省电模式，并把应用从清理名单中移除。
OnePlus（OxygenOS） 设置 → 应用 → RePhone Security → 打开允许后台运行（或在「电池优化」中选择不优化）；
设置 → 电池 → 关闭省电模式与睡眠待机优化。
OPPO / Realme（ColorOS） 设置 → 应用 → 应用管理 → RePhone Security → 打开允许后台运行、允许自启动、 允许关联启动；
设置 → 电池 → 应用耗电管理 → 允许完全后台行为。
Motorola（My UX） 设置 → 应用 → RePhone Security → 电池 → 不受限制；
设置 → 电池 → 关闭省电模式及自适应性能限制。
Sony Xperia 设置 → 应用 → RePhone Security → 电池 → 不优化；
设置 → 电池 → STAMINA 模式 → 把本应用加入例外。
Nothing Phone / 华硕 / 华为海外版（EMUI） 设置 → 应用 → RePhone Security → 电池 → 不受限制 / 不优化；
如有自启动开关请打开，并关闭系统省电模式。

三、网络、供电与使用习惯

  • 长期插电：低电量会触发系统更严格的限制。
  • 保持 Wi-Fi 常开：设置 → 网络 → Wi-Fi → 高级 → 休眠时保持 Wi-Fi 连接 → 始终。
  • 关闭「锁屏断网」类选项（部分 ROM 有）。
  • 不要上滑杀掉 App，改为在最近任务中锁定。
  • 熄屏模式：使用相机端页面的「熄屏模式」按钮，在屏幕熄灭时继续采集以省电。
  • 放置位置：通风散热良好、Wi-Fi 信号稳定的地方。

四、iPhone（iOS）做相机端

  • 关闭低电量模式：设置 → 电池 → 低电量模式。
  • 开启后台应用刷新：设置 → 通用 → 后台 App 刷新。
  • 建议接电源：iOS 在使用电池时会更积极地暂停后台任务。
  • 锁屏会暂停采集：iPhone 锁屏后系统会限制摄像头，App 会提示 「锁屏后将无法正常采集视频」。请使用相机端的「熄屏模式」，它会阻止自动锁屏以保持采集。
  • 不要在多任务界面上滑关闭 App。
  • 授予相机、麦克风、通知权限。

五、仍然掉线时的自检清单

  1. 监控端列表显示离线 → 到相机端手机上确认 App 是否仍在前台、通知栏「相机端运行中」是否还在。
  2. 相机端显示「已连接服务器 (ID: xxxx)」但监控端连不上 → 后台被冻结，回到本页 §1、§2 检查。
  3. 路由器重启或切换 Wi-Fi 后掉线 → 重启相机端 App，会自动重连。
  4. 只在夜间掉线 → 多为系统夜间清理 / 定时省电策略，检查相关设置。
