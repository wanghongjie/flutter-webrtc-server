常见问题：让相机端一直在线
RePhone Security：自启动 / 后台运行 / 电池优化设置指引（国内版）
更新日期：2026-10-10 · 适用：相机端手机（Android / iOS）
为什么要做这些设置？
RePhone Security 把一部闲置手机变成摄像头。为了省电，安卓系统默认会在锁屏一段时间后 冻结或杀掉后台应用，导致监控端连不上相机。 只要把下面 3 件事做好，相机端就能长期稳定在线： ① 关闭电池优化、② 允许后台运行/自启动、③ 开启通知权限（保持前台服务常驻）。
目录

一、先做这 3 步（所有安卓手机通用）

  1. 关闭电池优化：进入相机端时，App 会先弹出说明弹窗告知该权限的用途， 您点击「同意并继续」后才会跳转到系统的电池优化授权页，请选择「允许 / 不优化」。 若点了「暂不开启」，本次将不再提示（也不会频繁打扰）， 您可随时到：设置 → 应用 → RePhone Security → 电池/电量 → 选择 「不受限制 / 不优化 / 允许后台高耗电」。
  2. 开启通知权限：相机端靠「常驻通知」保持前台服务。进入相机端时 App 同样会 先说明用途再申请；若您关闭了通知权限， App 会提示「需要通知权限以保持相机在后台运行」，请到 设置 → 应用 → RePhone Security → 通知管理 打开允许通知。
  3. 允许自启动 / 后台运行：设置 → 应用 → 应用管理 → RePhone Security → 自启动（或「允许后台运行」） 打开； 同时在多任务（最近任务）界面长按本应用卡片，点「锁定 / 加锁」，防止一键清理时被清掉。
怎么确认设置成功了？
进入相机端后，若看到提示「电池优化已关闭，运行状态良好」，且通知栏常驻 「相机端运行中」的通知，说明配置正确。 若提示「建议在设置中关闭电池优化以保证连接稳定」，说明第 1 步还没生效。

二、各品牌手机的具体路径（Android）

不同系统版本菜单名称略有差异，请按「关键词」在设置中搜索（如搜索「电池优化」「自启动」「后台」）。

品牌 / 系统操作路径
华为 / 荣耀（EMUI、HarmonyOS、MagicOS） ① 手机管家 → 应用启动管理 → 找到 RePhone Security → 关闭「自动管理」，手动打开 自启动、关联启动、后台活动；
② 设置 → 应用 → 应用管理 → RePhone Security → 电池 → 「允许后台高耗电」；
③ 设置 → 电池 → 关闭省电模式 / 超级省电。
小米 / 红米（MIUI、HyperOS） ① 设置 → 应用设置 → 应用管理 → RePhone Security → 自启动 打开；
② 同一页面 → 省电策略 → 选择 「无限制」；
③ 手机管家 → 电池与性能 → 关闭省电模式；若开启「锁屏后清理内存」请设为「从不」或把应用加入保护名单。
OPPO / 一加 / realme（ColorOS、OxygenOS） ① 设置 → 应用 → 应用管理 → RePhone Security → 允许后台运行、允许自启动、允许关联启动；
② 设置 → 电池 → 应用耗电管理（或「后台耗电管理」）→ RePhone Security → 打开 「允许后台运行 / 允许完全后台行为」；
③ 关闭省电模式与「睡眠待机优化」。
vivo / iQOO（OriginOS、Funtouch） ① i管家 / 设置 → 应用与权限 → 权限管理 → RePhone Security → 自启动 打开；
② 设置 → 电池 → 后台耗电管理 / 高耗电后台运行 → 允许；
③ 设置 → 电池 → 关闭省电模式 / 睡眠模式。
三星（One UI 国行） ① 设置 → 电池与设备护理 → 电池 → 后台使用限制 → 关闭「让未使用的应用进入休眠」， 或把 RePhone Security 加入「从不休眠的应用」；
② 设置 → 应用程序 → RePhone Security → 电池 → 「不受限制」；
③ 若安装了「智能管理器」，在其中把应用加入不受监控的应用。
魅族（Flyme） ① 手机管家 → 权限管理 → 自启动 → 允许；
② 设置 → 电量管理 → 待机耗电管理 / 后台运行权限 → 允许；
③ 关闭低电量模式。
其他品牌 / 原生安卓 设置 → 应用 → RePhone Security → 电池 → 「不受限制 / 不优化」； 设置 → 电池 → 关闭省电模式与自适应电池对该应用的限制。

三、网络、供电与使用习惯

  • 长期插电：相机端建议一直接充电器，避免系统进入低电量限制。
  • 保持 Wi-Fi 常开：设置 → WLAN → 高级设置 → 打开「在休眠状态下保持 WLAN 连接（始终）」。
  • 关闭「锁屏断网 / 休眠断网」：部分 ROM 会在锁屏几分钟后断网。
  • 不要上滑杀掉 App：清理后台时请把相机端加入保护/锁定名单。
  • 熄屏模式：相机端提供「熄屏模式」按钮，可在保持采集的同时让屏幕熄灭以省电。
  • 放置位置：放在散热良好、Wi-Fi 信号稳定的地方，避免高温导致系统强制降频或关机。

四、iPhone（iOS）做相机端

iOS 没有「电池优化白名单」这类设置，但系统限制更严格，请注意：

  • 关闭低电量模式：设置 → 电池 → 低电量模式 关闭。
  • 开启后台应用刷新：设置 → 通用 → 后台 App 刷新 → 打开（App 与 WLAN）。
  • 接上电源：iOS 在低电量或长时间后台时会更积极地暂停任务，建议插电使用。
  • 锁屏会暂停采集：iPhone 锁屏后系统会限制摄像头采集，App 会提示 「锁屏后将无法正常采集视频」。请使用相机端页面的「熄屏模式」， 它会阻止设备自动锁屏，保持画面采集。
  • 不要上滑关闭 App：上滑杀掉后需要重新打开相机端。
  • 授予相机、麦克风、通知权限：设置 → RePhone Security 中开启。

五、仍然掉线时的自检清单

  1. 监控端列表里该相机显示离线 → 先到相机端手机上确认 App 是否还在前台、通知栏「相机端运行中」是否存在。
  2. 相机端显示「已连接服务器 (ID: xxxx)」但监控端仍连不上 → 通常是相机端后台被冻结，回到本页 §1、§2 检查。
  3. 切换到别的 Wi-Fi 或重启路由器后掉线 → 重启相机端 App 即可自动重连。
  4. 整夜掉线、白天正常 → 多为「睡眠待机优化 / 定时清理」导致，检查系统是否设置了夜间自动清理或省电。
