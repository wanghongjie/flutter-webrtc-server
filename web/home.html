三步开启监控之旅

简单配置，零门槛上手，无需专业知识

下载与安装

在您闲置的手机（摄像头端）和日常使用的主手机（监控端）上分别安装 RePhone Security 应用。 应用支持 iOS 与 Android 双平台，适配主流机型。

登录与绑定

使用同一邮箱账号在两台设备上登录。首次登录后，通过二维码扫描或手动输入的方式， 将摄像头端设备绑定到您的账号下，完成设备配对。

部署与监控

将摄像头端手机放置在需要监控的位置，连接稳定 Wi-Fi 网络并授予摄像头、麦克风权限。 在主手机上即可随时查看实时画面、接收告警通知，并开通云端回看功能。

隐私政策

我们非常重视您的个人信息与隐私保护

RePhone Security 隐私协议

生效日期：2026-01-17 · 版本：V1.0
查看完整政策 →

1. 我们收集哪些信息

账号与登录信息：邮箱地址用于登录与账号识别，验证码信息用于完成登录认证。

设备与运行信息：设备型号、系统版本、应用版本、网络类型、IP 地址以及必要的崩溃日志、 错误码等性能数据，用于保障服务稳定与故障排查。

设备绑定信息：摄像头设备标识、相机名称、位置备注及在线状态等，用于实现多设备绑定与管理。

WebRTC 连接信息：信令信息（会话标识、SDP、ICE 候选等）用于建立点对点连接； STUN（如 stun.l.google.com）和 TURN 中继服务用于 NAT 穿透与保障连接可达。

2. 关于音视频内容

我们不会主动保存您的音视频内容到服务器。在默认情况下，音视频流通过点对点或 TURN 中继进行传输， 不做持久化存储。当您选择开启云端录像存储功能时，录像文件会加密存储在云端服务器， 仅您本人可通过登录账号查看或删除。

3. 我们如何使用信息

  • 提供与维护核心功能：登录、绑定、音视频连接、设备管理、告警推送等。
  • 保障账号与服务安全：反作弊、防滥用、风险控制与访问授权验证。
  • 进行故障排查、性能分析与产品体验优化。

4. 信息共享与保护

我们仅在必要情形下与第三方共享信息（如广告 SDK、STUN/TURN 服务提供方、依法合规要求）， 并采取合理的安全措施（传输加密、访问控制、最小权限等）保护您的个人信息。 除非获得您明确同意或法律法规另有规定，我们不会转让或公开披露您的个人信息。

5. 您的权利

  • 访问、更正您的账号信息（如邮箱地址）。
  • 退出登录或清除应用数据以清理本地存储信息。
  • 在系统设置中撤回相机、麦克风、相册等权限授权（可能影响部分功能使用）。
  • 就隐私相关问题通过联系邮箱向我们咨询或提出请求。

6. 未成年人保护

本服务不面向未满 14 周岁的未成年人提供。若您为未成年人，请在监护人同意与指导下使用本服务。

常见问题

您可能关心的问题，都在这里

RePhone Security 是如何工作的？

您可以把一部闲置手机作为摄像头设备，在上面登录同一个账号； 然后在主用手机上也登录该账号，即可看到摄像头手机的实时画面。 摄像头手机会通过 WebRTC 加密连接把视频进行传输，您的查看设备可以实时观看、接收告警， 并在开通云端存储后回看历史录像。

无法连接到摄像头手机怎么办？
  • 请确认两部手机都已连接网络（摄像头手机建议使用稳定 Wi-Fi）。
  • 确保在两台设备上使用的是同一个账号登录。
  • 检查摄像头手机是否授予了应用摄像头、麦克风等必要权限。
  • 尝试在两台设备上分别关闭并重新打开 App。
  • 如果仍无法连接，建议切换网络环境或重启路由器后重试。
视频画面会被其他人看到吗？

不会。我们采用传输加密技术保障音视频数据安全，只有登录同一账号的设备才能查看对应摄像头画面。 默认情况下我们不会在服务器保存音视频内容，云端录像功能开通后也仅您本人可通过账号查看和删除。 请妥善保管您的账号密码，不要将账号告知他人。

订阅和内购相关问题
  • 所有购买和订阅均由应用商店平台（Apple/Google）通过您的账号进行管理和扣费。
  • 您可以在设备的「设置 > Apple ID > 订阅」或 Google Play 的订阅管理中查看或取消订阅。
  • 如果购买后没有正确解锁会员，请在 App 中使用「恢复购买」或「刷新会员状态」功能， 若仍未生效，请带上大致购买时间联系我们的客服邮箱。
摄像头手机需要一直亮屏吗？

不需要。RePhone Security 支持后台运行与熄屏录像，摄像头端在完成配置并进入监控模式后， 可自动关闭屏幕以节省电量。建议将摄像头手机连接电源长期使用，并确保 Wi-Fi 信号稳定。
