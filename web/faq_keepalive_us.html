FAQ: Keeping the Camera Phone Online
Autostart / Background Activity / Battery Optimization (International)
Last updated: 2026-10-10 · Applies to: the camera phone (Android / iOS)
Why do I need to change these settings?
RePhone Security turns a spare phone into a camera. To save battery, Android freezes or kills background apps after the screen has been off for a while, which makes the camera go offline. Three things keep it alive: ① disable battery optimization, ② allow background activity / autostart, and ③ allow notifications (needed for the foreground service).
Contents

1. Three steps for every Android phone

  1. Turn off battery optimization: the first time you open the camera mode, the app shows the system battery-optimization dialog — choose Allow / Don't optimize. If you dismissed it: Settings → Apps → RePhone Security → Battery → Unrestricted / Not optimized.
  2. Allow notifications: the camera keeps running via a persistent notification. If notifications are blocked the app shows "Notification permission is required to keep camera running in background". Go to Settings → Apps → RePhone Security → Notifications and enable them.
  3. Allow background activity / autostart: Settings → Apps → RePhone Security → Mobile data & Wi-Fi → enable Background data and (if present) Unrestricted data usage; then in the Recent apps screen long-press the app card and choose Lock so "Clear all" will not remove it.
How do I know it worked?
The camera screen shows "Battery optimizations disabled, running well" and a persistent notification "Camera mode active" is visible. If you see "Consider disabling battery optimizations to keep connection stable", step 1 is not applied yet.

3. Power, network and daily habits

  • Keep it plugged in: low battery triggers aggressive system restrictions.
  • Keep Wi-Fi always on: Settings → Network → Wi-Fi → advanced → Keep Wi-Fi on during sleep → Always.
  • Disable "disconnect when screen off" style options if your ROM has them.
  • Do not swipe the app away; lock it in the recent-apps list instead.
  • Screen-off mode: use the in-app Screen-off mode button to keep capturing while the display is dark.
  • Placement: keep the device cool and within good Wi-Fi coverage.

4. iPhone as the camera device (iOS)

  • Turn off Low Power Mode: Settings → Battery → Low Power Mode off.
  • Enable Background App Refresh: Settings → General → Background App Refresh → on (Wi-Fi and Cellular).
  • Keep it charging: iOS suspends work more aggressively on battery.
  • Locking the screen pauses capture: iOS restricts the camera after lock, and the app warns "Video capture will pause when the device is locked." Use the in-app Screen-off mode, which prevents auto-lock and keeps capturing.
  • Do not swipe the app up in the app switcher.
  • Grant Camera, Microphone and Notifications permissions.

5. Still going offline?

  1. The camera shows offline in the list → check on the camera phone whether the app is still open and the "Camera mode active" notification is present.
  2. The camera shows "Connected to server (ID: …)" but the monitor cannot connect → its background was frozen; re-check sections 1 and 2.
  3. Offline after a router reboot or Wi-Fi change → restart the camera app; it reconnects automatically.
  4. Offline overnight only → a nightly cleaning / power-saving schedule is usually the cause.
