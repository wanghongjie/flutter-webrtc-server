会员权益与取消订阅
RePhone Security 会员说明（国际版）
更新日期：2026-10-10 · 适用版本：国际版（App Store / Google Play 订阅）
一句话说明
国际版会员由 苹果 App Store 或 Google Play 提供自动续期订阅， 支付成功后立即生效；可随时在购买所用的商店中取消， 取消后当期结束时停止续费（当期权益仍然保留）。

一、会员权益何时生效

1.1 一般立即生效

  1. 您在 App Store / Google Play 完成购买；
  2. App 把商店收据发送到我们的服务器；
  3. 服务器向苹果 / 谷歌校验收据（不信任设备端结果）；
  4. 校验通过即解锁高级版，通常只需几秒钟。

1.2 会员时长

  • 月卡：一个月，每月自动续期；
  • 年卡：一年，每年自动续期；
  • 在您取消之前，每个周期结束时会自动续费。

1.3 已付款但未显示会员

  1. 关闭并重新打开「会员」页面（会重新向服务器同步）；
  2. 点击会员页的「恢复购买」，把商店收据重新提交给服务器；
  3. 确认登录的是购买时使用的同一个邮箱账号；
  4. 等待几分钟后重试（商店回调偶有延迟）；
  5. 仍未恢复，请发送账号邮箱 + 商店订单号至 dahongwudi123@gmail.com。

三、如何取消订阅

3.1 在 iPhone / iPad（App Store）

  1. 打开 iOS 「设置」；
  2. 点顶部的 Apple ID 名称；
  3. 点 「订阅」；
  4. 选择 RePhone Security → 「取消订阅」。

3.2 在 Android（Google Play）

  1. 打开 Google Play 商店；
  2. 点右上角头像；
  3. 点 「付款与订阅 → 订阅」；
  4. 选择 RePhone Security → 「取消订阅」并按提示确认。

3.3 取消之后

  • 权益保留到当前计费周期结束；
  • 到期后不再扣款；
  • 取消 ≠ 退款（见第四节）；
  • 卸载 App 不会取消订阅，请在商店中取消。

四、退款

国际版由苹果 / 谷歌收款，退款遵循其政策：

  • 苹果：在 reportaproblem.apple.com 登录后申请；
  • 谷歌：Play 商店 → 订单记录 中申请，或通过 Google Play 帮助中心；
  • 也可联系 dahongwudi123@gmail.com，我们可协助核实，但最终由商店裁定。

退款成功后，相应会员时长会被回收。

五、其他常见问题

5.1 换手机 / 重装 App

用同一邮箱登录，再点会员页的「恢复购买」即可，无需重复购买。

5.2 恢复购买提示没有记录

请确认使用的是购买时的 Apple ID / Google 账号，且登录的是同一个 RePhone 账号邮箱。

5.3 相机端需要买会员吗？

不需要。相机端无需登录、无需购买，会员权益作用于监控端账号。
