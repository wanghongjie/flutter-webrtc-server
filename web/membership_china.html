一、会员权益何时生效

1.1 正常情况：支付成功后 1 分钟内生效

您在 App 内完成微信支付后，会按以下链路发放权益：

  1. 微信支付成功，微信把支付结果异步通知我们的服务器；
  2. 服务器不信任手机端结果，会主动向微信查单确认该订单确实为「支付成功」；
  3. 确认无误后写入会员时长，您的会员立即生效。

同时，App 在支付返回后会自动做一次「确认 + 轮询」（最多约 8 次、几十秒内）， 因此绝大多数情况下，支付成功后几秒到 1 分钟内会员页就会显示为「高级版」并显示到期时间。

1.2 会员时长如何计算

  • 月卡：增加 30 天；年卡：增加 365 天。
  • 如果您当前已经是会员且未过期，新购时长会在原到期时间上累加（例如原到期 2026-11-01 购买月卡，到期变为 2026-12-01）。
  • 如果会员已过期或未开通，则从当前时间开始计算。

1.3 支付成功但会员没到账怎么办

请按以下顺序排查（绝大多数在第 1 步即可恢复）：

  1. 重新进入「会员」页面：退出会员页再进入，App 会自动向服务器刷新一次权益状态。
  2. 确认微信已真实扣款：打开微信 →「我 → 服务 → 钱包 → 账单」，确认该笔订单状态为「支付成功」。若显示「已退款/未支付」，说明并未完成付款。
  3. 确认登录的是同一个账号：会员绑定在购买时登录的邮箱账号上，换账号登录看不到。
  4. 等待 5 分钟后重试：极端情况下微信回调有延迟，服务器最长会在下一次刷新时自动补发。
  5. 仍未到账，请把微信账单截图（含订单号）+ 登录邮箱发送至客服邮箱 dahongwudi123@gmail.com，我们会人工核对补发。
为什么不能「下单即开通」？
为了防止「刚弹出收银台、还没付款就白拿会员」，服务器只认微信返回的「支付成功」状态， 不会根据手机端的任何自报结果发放权益。这也是上面第 2 步要核对微信账单的原因。

三、如何取消订阅

3.1 国内版：无需取消，也不会自动续费

国内版为单次购买（月卡 / 年卡），不签约自动续费、不开启免密代扣， 购买成功后微信不会在到期时自动扣款，到期即自动停止会员权益。

  • 因此没有「取消订阅」入口，也不需要任何取消操作；
  • 若想继续用，到期后在会员页重新购买即可；
  • 不用担心「忘记取消被扣钱」——国内版不存在这种扣款。
会员页出现「来自 iOS / Android 的订阅」？
若您的账号曾在海外版（App Store / Google Play）购买过订阅，会员会按渠道区分管理： 海外渠道的订阅需要在原购买渠道（苹果/谷歌）取消，微信渠道不受影响。 这种情况请联系客服协助处理。

3.2 如果您是在 iOS 上购买的（国内版不含此渠道，仅供参考）

若您使用的是海外版并在苹果渠道购买，请到：系统设置 → 顶部 Apple ID → 订阅 中取消。

四、退款说明

国内版退款请按以下方式申请：

  1. 打开微信 →「我 → 服务 → 钱包 → 账单」，找到 RePhone Security 的这笔订单；
  2. 进入订单详情 →「对订单有疑惑 / 联系商户」，按微信引导提交退款申请；
  3. 也可直接发送邮件至 dahongwudi123@gmail.com，提供登录邮箱 + 微信订单号 + 购买时间。
  • 未使用的会员时长：核实后按剩余时长处理；
  • 已使用的会员期间：一般不支持退款，具体以微信支付退款规则与双方协商结果为准；
  • 退款成功后，对应会员时长会被回收。

五、其他常见问题

5.1 换手机 / 重装 App 后会员还在吗？

在。会员与邮箱账号绑定，重新登录同一账号即可恢复，无需重复购买。

5.2 可以同时买月卡和年卡吗？

可以。时长会累加到同一账号的到期时间上。

5.3 支付时提示失败 / 无法调起微信

  • 确认手机已安装微信并登录；
  • 确认网络正常，切换 Wi-Fi / 移动数据后重试；
  • 同一时间不要重复点击购买（App 内有防重复点击保护）。

5.4 相机端（被监控的旧手机）需要买会员吗？

不需要。相机端无需登录、无需购买，会员权益作用于监控端账号。
